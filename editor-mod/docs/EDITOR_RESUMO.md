# Editor Visual — Guia rápido (menos técnico)

Este guia explica o editor de forma simples, focando no uso no dia a dia.

## O que é
- Um “quadro branco” inteligente para montar cenas com formas, textos e atores.
- Serve para desenhar ideias, organizar histórias e apresentar visualmente.

## Partes principais
- Barra superior: escolhe ferramentas (retângulo, círculo, linha, seta, texto, ator), desfaz/refaz, dá zoom e exporta.
- Lateral: ajusta cores, tamanhos e texto; gerencia atores e cenas.
- Área central: é o quadro onde você desenha, seleciona e arrasta os elementos.

## Como usar no dia a dia
- Escolha uma ferramenta na barra superior e clique/arraste no quadro para criar.
- Clique em um elemento para selecionar; arraste um retângulo para selecionar vários.
- Use as “alças” (pequenos quadrados) nos cantos para redimensionar.
- Segure `Space` para “arrastar a tela” (mover a visão) e use zoom para aproximar/afastar.
- Para apagar, selecione e pressione `Delete`.

## Atores
- Na aba de Atores, arraste um ator para o quadro.
- Defina nome, iniciais, cor e formato (círculo/quadrado).
- Adicione fala; o editor mostra um balão ao lado do ator.

## Cenas (como slides)
- Pense em cada cena como um slide diferente da sua apresentação.
- Crie, duplique e renomeie cenas pela aba de Cenas.
- Navegue com as setas do teclado (esquerda/direita) ou use o modo Slideshow para apresentar automaticamente.

## Grupos e camadas
- Agrupar junta elementos para mover/redimensionar juntos.
- “Soldar” fixa uma relação visual do grupo (o contorno aparece destacado).
- Trazer para frente/mandar para trás controla quem fica por cima.

## Exportar e salvar
- Exporta como imagem ou arquivo para compartilhar/guardar.
- O editor salva seu trabalho associado ao projeto (você precisa estar logado).

## Dicas úteis
- `Ctrl+Z` desfaz; `Ctrl+Y` refaz.
- `Ctrl+A` seleciona tudo.
- Segurar `Shift` ajuda a alinhar elementos com mais precisão (snap).
- Se estiver digitando em um campo de texto, os atalhos não atrapalham.

## Limitações conhecidas
- É necessário login para salvar/carregar.
- O zoom tem limites para manter a experiência estável.
